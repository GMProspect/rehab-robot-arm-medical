## 📖 About the Project
A multidisciplinary project focused on creating an accessible Continuous Passive Motion (CPM) system for physical therapy. This robotic arm allows healthcare professionals to customize movements and parameters to aid patient recovery effectively.

## ✨ Key Features
- ⚙️ **Custom Firmware**: Highly specialized control logic for precise, smooth movements.\n- 🖨️ **Cost-Effective Build**: Design optimized for 3D printing and accessible electronics.\n- 🩺 **Clinical Parameters**: Clinically-guided movement parameters for safe and effective rehabilitation.
